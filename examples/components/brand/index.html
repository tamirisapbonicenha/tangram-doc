Customizado​

É possível usar outros logotipos também.

Utilizando como link​

É possível adicionar um link ao componente através das propriedades as e href.

Use o atributo target="_blank" para o link abrir em uma nova aba do navegador. Ao usar esse atributo, é recomendado sempre definir rel="noopener" ou rel="noreferrer" quando conectado a conteúdo de terceiros.

Dica

rel="noopener" impede que a nova página acesse a propriedade window.opener e garante que ela seja executada em um processo separado.

Sem isso, a página de destino pode potencialmente redirecionar sua página para uma URL mal-intencionada.

rel="noreferrer" tem o mesmo efeito, mas também impede que o cabeçalho Referer seja enviado para a nova página.

Propriedade as como componente​​

Crie um invólucro customizado para o componente Brand através da propriedade as. Por exemplo:

const ReplacedComponent = ({ children, ...rest }) => {
  return <button {...rest}>{children}</button>;
};

<Brand as={ReplacedComponent} />;
